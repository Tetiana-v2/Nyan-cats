# Starbase Survival

Прототип кооперативної космічної гри для 3 гравців.

## Як запустити

1. Відкрийте термінал у папці проєкту.
2. Запустіть:

   python -m http.server 8000

3. Відкрийте у браузері:

   http://localhost:8000

## Геймплей

- Кімната для 3 людей: капітан, інженер, офіцер.
- Кожен гравець обирає дію у раунді.
- Командні рішення змінюють ресурси станції: O₂, енергія та кредити.
- Якщо ресурси падають нижче критичних значень — поразка.
- Після кількох раундів команда може стабілізувати станцію та перемогти.

## Технології

- HTML
- CSS
- JavaScript
- Підготовка до Firebase Realtime Database для мережевої синхронізації
